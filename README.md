# 볼린저밴드 과매도 반등 스캐너

S&P 500과 내 관심종목(약 680종목) 가운데, **상승 추세 종목이 볼린저밴드 하단을 과하게 이탈한 뒤 반등을 확인한** 종목을 찾아 목표가·손절가·손익비와 함께 디스코드로 보냅니다. 매일 미국 장 마감 후 1회 실행됩니다.

## 알림 조건 (모두 충족해야 알림)

"이탈일"은 밴드 하단을 크게 뚫고 마감한 날입니다 (어제 또는 오늘).

| 구분 | 조건 |
|---|---|
| ① 과도한 이탈 | 이탈일 종가가 볼린저밴드(20일, 2σ) 하단 아래, %B < -0.1 |
| ② 단기 과매도 | 이탈일 RSI(2) < 5 **또는** RSI(14) < 30 |
| ③ 상승 추세 | 오늘 종가 > 200일선 |
| ④ 반등 확인 | **BACK**: 어제 이탈 → 오늘 밴드 안으로 복귀 마감 / **TAIL**: 오늘 이탈했지만 종가가 당일 범위 상단 절반 (아래꼬리) |
| ⑤ 투매 거래량 | 이탈일 거래량 ≥ 직전 50일 평균의 1.5배 |
| ⑥ 악재 갭 제외 | 이탈일~오늘 중 시가가 전일 종가보다 8% 이상 낮게 시작한 날이 없음 |
| ⑦ 200일선 거리 | 오늘 종가가 200일선 위 0~15% |
| 기본 필터 | 주가 $5 이상, 50일 평균 거래대금 $500만 이상 |
| 기타 | 종가가 이미 중심선(20일선) 위면 제외 (먹을 구간이 없음) |

## 디스코드 표 보는 법

| 열 | 의미 |
|---|---|
| TYPE | BACK = 밴드 안 복귀형, TAIL = 아래꼬리 반전형 |
| %B | 이탈일 %B. 0이면 하단, 음수일수록 더 깊이 이탈 |
| RSI2 / RSI14 | 이탈일 RSI |
| VOLx | ⑤ 이탈일 거래량 ÷ 50일 평균 |
| GAP% | ⑥ 이탈일~오늘 중 가장 큰 갭하락(%). -8보다 작으면 제외됨 |
| 200% | ⑦ 오늘 종가가 200일선보다 몇 % 위인지 |
| LAST | 오늘 종가 |
| TARGET | 목표가 = 볼린저밴드 중심선(20일선) |
| STOP | 손절가 = 이탈일 이후 최저가 |
| R:R | 손익비 = (목표가 − 종가) ÷ (종가 − 손절가). 이 순서로 정렬 |

같은 종목은 5일 안에 다시 알리지 않습니다.

## 실행 시각

평일 한국 시각 **06:40** (미국 장 마감 후 확정 일봉 기준). GitHub 특성상 5~30분 늦을 수 있습니다.

## 설치 (새 저장소)

1. **디스코드 채널·웹후크**
   1. 채널 목록 **채팅 채널** 옆 **+** → 새 채널 생성 (예: `볼린저반등`)
   2. 새 채널 옆 **⚙** → **연동** → **웹후크** → **새 웹후크**
   3. 생긴 봇을 펼쳐 **채널**이 새 채널인지 확인 → **웹후크 URL 복사**
2. **GitHub 저장소**
   1. 오른쪽 위 **+** → **New repository** → 이름 입력 (예: `bb-scanner`) → **Public** → **Create repository**
   2. **uploading an existing file** → `bb.py`, `watchlist.txt`, `requirements.txt`, `README.md` 끌어다 놓기 → **Commit changes**
   3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` 입력 (슬래시를 치면 폴더가 자동 생성됨) → zip 안의 `main.yml` 내용 붙여넣기 → **Commit changes**
3. **웹후크 주소 등록**
   1. 새 저장소 **Settings** → 왼쪽 **Secrets and variables** → **Actions**
   2. **New repository secret** → Name: `DISCORD_WEBHOOK_URL` / Secret: 1-3에서 복사한 주소 → **Add secret**
4. **테스트**
   1. **Actions** 탭 → 왼쪽 **Bollinger Rebound Scanner** → **Run workflow** → **Run workflow**
   2. 몇 분 뒤 새 채널에 `✅ 볼린저 스캐너 테스트 완료: N종목 확인` 메시지가 오면 끝 (N이 680 안팎이면 정상)

## 설정 바꾸기 (`bb.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `BB_LEN` / `BB_STD` | 20 / 2.0 | 볼린저밴드 기간·표준편차 |
| `PCTB_MAX` | -0.1 | ① 이탈 깊이 기준 |
| `LOOKBACK` | 1 | ④ 이탈일이 며칠 전까지 복귀형으로 인정되는지 |
| `RSI2_MAX` / `RSI14_MAX` | 5 / 30 | ② 과매도 기준 |
| `VOL_SPIKE` | 1.5 | ⑤ 투매 거래량 배수 (`REQUIRE_VOL_SPIKE`를 0으로 하면 해제) |
| `GAP_DOWN_PCT` | 8 | ⑥ 제외할 갭하락 크기 (`REQUIRE_NO_GAP`를 0으로 하면 해제) |
| `MAX_ABOVE_200` | 15 | ⑦ 200일선 위 최대 거리(%) |
| `REALERT_DAYS` | 5 | 같은 종목 재알림 금지 기간(일) |
